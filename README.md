# 명언 터미널

> **개발 중인 프로젝트입니다.** 기능과 명언 데이터를 계속 다듬고 있습니다.

CRT 터미널 화면에서 명언을 탐색하고 음성으로 들을 수 있는 정적 웹앱입니다. 별도 서버나 빌드 과정 없이 브라우저에서 동작합니다.

## 주요 기능

- 카테고리별 명언 필터와 무작위 명언 실행
- 이전 명언으로 돌아가기
- 한국어 번역문과 원문 함께 표시
- 저자, 문헌, 출처, 원문 언어 정보 표시
- 한국어 번역문과 영어 원문 음성 읽기
- 읽는 구간 표시와 명언 복사
- CRT 스캔라인과 글로우 효과
- 모바일과 데스크톱 반응형 화면

## 데이터

명언은 [`quotes-data.js`](./quotes-data.js)에 정적으로 포함되어 있습니다.

| 항목 | 개수 |
| --- | ---: |
| 저자 및 문헌 | 25개 |
| 명언 | 446개 |
| 카테고리 | 9개 |

## 검증

JavaScript 문법은 다음 명령으로 확인합니다.

```powershell
node --check app.js
node --check quotes-data.js
```

명언 데이터 변경 시 전체 개수와 누락된 저자 연결도 함께 확인합니다.

## 참고

음성 읽기는 브라우저의 Web Speech API를 사용합니다. 목소리와 지원 언어는 운영체제와 브라우저 환경에 따라 달라질 수 있습니다.
